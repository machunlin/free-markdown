## [0.1.0-alpha] — Not yet released

### Added
- Basic window layout with toolbar, tab bar, and status bar
- CodeMirror 6 markdown source editor
- markdown-it preview rendering with GFM support
- Multi-tab support (new, close, switch)
- File open/save via native dialogs (UTF-8)
- Native macOS menu bar and keyboard shortcuts
- 3 preset themes (Office, Night, Programmer) with Dark/Light mode
- Shiki syntax highlighting for code blocks
- Undo/Redo per tab
- Recent files
- File drag-and-drop support
